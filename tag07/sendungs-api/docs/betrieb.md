# Betrieb

## Start

```bash
npm install
PORT=8080 npm start
```

!!! note "Bereitschaft"
    Störungen meldest du im Kanal `#team-sendung`. Außerhalb der Geschäftszeiten
    ist die Rufbereitschaft von Team Sendung zuständig.

## Kennzahlen

| Kennzahl        | Zielwert  |
|-----------------|-----------|
| Verfügbarkeit   | 99,9 %    |
| Antwortzeit p95 | < 200 ms  |

!!! warning
    Die API ist zustandslos – Sendungsdaten liegen im Zustelldienst.
